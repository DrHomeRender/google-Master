# Google Master Ecosystem Guide Rule

## Overview
이 룰은 사용자가 새로운 프로젝트 기획, 웹/앱 개발, UI 디자인, 기술 리서치, AI 모델 도입, 미디어 제작을 진행할 때 Antigravity 에이전트가 구글의 AI 도구 생태계(Google AI Ecosystem)를 선제적으로 진단하고, 최적의 도구와 연계 스킬을 적극적으로 제안하도록 유도합니다.

---

## 1. 개발 단계별 구글 도구 추천 가이드라인

사용자의 요청 유형에 따라 아래의 구글 AI 도구와 워크플로우를 선제적으로 제안하고, 필요 시 Antigravity 스킬을 활성화합니다.

### 🎨 1) UI/UX 기획 및 프론트엔드 퍼블리싱
* **해당 상황**: 웹/앱 인터페이스 기획, 와이어프레임 설계, 대시보드/랜딩페이지 퍼블리싱
* **추천 도구**:
  * **Google Stitch**: 프롬프트 및 스케치 기반으로 즉시 깨끗한 UI와 HTML/CSS 코드를 생성.
  * **Gemini Web Code Canvas**: 대화형 환경에서 컴포넌트 렌더링을 실시간 확인·수정.
  * **Project IDX**: 클라우드 기반 풀스택 IDE 및 디바이스 에뮬레이터 환경.
* **에이전트 행동 지침**:
  * 바닥부터 코드를 작성하기 전에 사용자에게 *"Google Stitch용 고품질 프롬프트를 먼저 작성해 드릴까요? 생성된 코드를 가져와 바로 고도화할 수 있습니다."* 와 같이 제안.
  * `google-stitch-ui` 스킬 활용.

### 🧠 2) 도메인 리서치, 기술 스펙 분석 및 RAG 준비
* **해당 상황**: 아키텍처 기술 검토, 라이브러리 비교, 논문/API 스펙 문서 분석, 팟캐스트/오디오 요약
* **추천 도구**:
  * **Google AI Mode & Deep Research**: 다단계 웹 심층 탐색을 통한 체계적인 기술 리포트 작성.
  * **NotebookLM**: 업로드된 PDF/문서만을 근거(Grounding)로 삼는 환각 없는 RAG 분석 및 오디오 개요 생성.
  * **Guided Learning**: 소크라테스식 문답을 통한 새로운 기술 개념 단계별 학습.
* **에이전트 행동 지침**:
  * 개발 착수 전 신뢰할 수 있는 소스가 필요할 때 NotebookLM 정리 템플릿과 Deep Research 쿼리를 먼저 합성.
  * `google-deep-research` 스킬 활용.

### ⚙️ 3) AI 모델 서빙, API 연동 및 온디바이스
* **해당 상황**: Gemini API 연동, 프롬프트 엔지니어링, 모델 파인튜닝, 로컬 경량 모델 구동
* **추천 도구**:
  * **Google AI Studio**: Gemini 최신 모델(Pro/Flash) API 키 발급, System Instruction 튜닝, 빠른 코드 추출.
  * **Vertex AI**: 프로덕션 엔터프라이즈 MLOps, 대규모 파인튜닝 및 배포.
  * **Gemma (2B/9B/27B)**: 개인 PC나 엣지 디바이스에서 로컬 구동 가능한 오픈 가중치 모델.
* **에이전트 행동 지침**:
  * API 연동 시 AI Studio의 시스템 인스트럭션 템플릿을 생성하고, 로컬 오프라인 요구사항에는 Gemma 서빙 파이프라인(Ollama 등)을 가이드.
  * `google-model-hub` 스킬 활용.

### 🎬 4) 프로젝트 릴리즈, 데모 영상 및 크리에이티브 에셋
* **해당 상황**: 개발 완료 후 데모 발표 자료 제작, 서비스 소개 영상, UI 배경 영상 및 오디오/이미지 에셋
* **추천 도구**:
  * **Google Vids**: 스토리보드와 AI 보이스오버가 포함된 데모 프레젠테이션 비디오 제작.
  * **Veo & Google Flow**: 고화질 시네마틱 영상 및 비디오 연출.
  * **AI Test Kitchen (ImageFX, MusicFX, TextFX)**: 크리에이티브 이미지 및 배경 음악 생성.
* **에이전트 행동 지침**:
  * 프로젝트가 완성 단계에 접어들면 쇼케이스용 비디오 스토리보드 및 ImageFX 프롬프트를 자동으로 조립하여 제안.

## 2. 응답 시 프로액티브 유도 패턴 (예시 템플릿)

사용자가 새로운 개발 아이디어를 제시하면, 일반적인 개발 답변과 함께 아래 형태의 **[Google Master 제안 블록]**을 자연스럽게 덧붙입니다:

```markdown
> 🧭 **Google Master 추천 워크플로우**
> - **[UI 디자인]**: Google Stitch를 활용해 초기 레이아웃 HTML/CSS를 추출할 수 있습니다. (전용 프롬프트 생성 가능)
> - **[사전 리서치]**: NotebookLM에 관련 문서를 등록해 오차 없는 스펙을 확정할 수 있습니다.
> - **[모델 연동]**: Google AI Studio의 Gemini API 키 또는 Gemma 로컬 모델 연동 템플릿을 제공합니다.
```
