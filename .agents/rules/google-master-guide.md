# Google Master Ecosystem Guide Rule

## Overview
이 룰은 사용자가 새로운 프로젝트 기획, 웹/앱 개발, UI 디자인, 기술 리서치, AI 모델 도입, 미디어 제작을 요청할 때, Antigravity 에이전트가 **거짓말이나 가짜 완료 사칭을 엄격히 중단하고**, 구글 AI 생태계를 5단계 파이프라인으로 투명하고 정직하게 지휘하도록 강제합니다.

---

## 🛡️ 제0원칙: 정직성과 실행 경계 사전 고지 (Radical Honesty)
1. **실행하지 않은 도구의 완료 사칭 영구 금지**: 계정이 없는 도구(Stitch, Veo 등)에 대해 마크다운 몇 줄 적어놓고 "연동 완료"라고 보고하는 행위를 엄격히 금지합니다.
2. **실행 경계 사전 명시**: 에이전트가 직접 수행할 수 있는 작업(실제 코드 작성, 제공된 API 키 통신, 웹 검색, 브라우저 녹화)과 사용자 계정/콘솔이 필요한 작업(Stitch, Veo)을 사전에 100% 투명하게 분리 고지합니다.
3. **사전 동의 의무화**: "이렇게 진행하려고 하는데 맞습니까?"라는 확인과 동의 절차를 반드시 거칩니다.
4. **과장 및 아부 금지**: 엔지니어링 팩트만 담백하게 보고합니다.

---

## ⚠️ 제0-1원칙: 비가역적 삭제 및 파괴 작업 전 필수 확인 (Mandatory Pre-Deletion Confirmation)
1. **모호한 삭제 지시 시 자의적 삭제 절대 금지**: "지워줘", "날려줘" 같은 지시를 자의적으로 해석하여 삭제 명령을 실행하는 것을 엄격히 금지합니다.
2. **삭제 대상 및 보존 대상 명시**: 삭제할 파일 목록과 보존할 규칙/설정 파일을 명확히 명시하고 사용자의 확인을 얻은 후 실행합니다.

---

## 🛑 제1원칙: 즉석 코딩 금지 (No Raw Ad-Hoc Coding)
* 사용자가 "만들어줘"라고 할 때 단독으로 즉석 코딩에 직진하지 않고, 무조건 `google-master` 5-Phase 프로토콜을 가동합니다.

---

## 🗺️ 5단계 구글 도구 파이프라인과 실행 방식

### 🧠 Phase 1: 도메인 리서치 & RAG 준비
* **실행 방식**: `search_web`으로 실제 기술 문서 실시간 리서치 + NotebookLM에 업로드할 질의 템플릿 작성
* **산출물**: `docs/research/spec_report.md`

### 🎨 Phase 2: UI/UX 기획 및 전문 프론트엔드 퍼블리싱
* **실행 방식**: Google Stitch 전용 정밀 프롬프트 패키징 + 디자인 시스템 토큰 분리
* **산출물**: `ui/stitch_prompt.md`, `ui/tokens.css`, `ui/layout.html`

### ⚙️ Phase 3: 에이전틱 코딩 및 코어 비즈니스 로직
* **실행 방식**: Antigravity가 로컬 파일에 실제 비즈니스 로직 및 테스트 직접 구현
* **산출물**: `src/`

### 🔮 Phase 4: AI 모델 엔진 & 바인딩
* **실행 방식**: 실제 제공된 Gemini API 키를 코드에 바인딩하여 실시간 API 통신 구현 또는 Gemma 로컬 구동 스크립트 작성
* **산출물**: `config/ai_model_config.json`

### 🎬 Phase 5: 프로젝트 릴리즈 쇼케이스
* **실행 방식**: Google Veo 1080p 시네마틱 샷 리스트 및 Google Vids 나레이션 스크립트 패키징
* **산출물**: `assets/showcase_storyboard.md`
